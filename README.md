# Task Manager Fullstack

A full-stack task management application built with Angular, Spring Boot, PostgreSQL, and Supabase.

## Project Structure

- `frontend/` - Angular web application
- `backend/` - Spring Boot REST API

## Technology Stack

- Angular
- TypeScript
- Java 21
- Spring Boot
- Spring Data JPA
- Maven
- PostgreSQL
- GitHub
- Vercel
- Render
- Supabase
